# Getting Started
Prerequisites
Install Expo Go on your mobile device (iOS or Android).
Have Node.js  (>= 18) and npm/yarn installed if you want to run locally.
Clone this repository.

Running Locally
bash
# Install dependencies
npm install
# or
yarn install

# Start the Expo development server
npm run start
# or
yarn start
Scan the QR code with Expo Go on your device.

The app will open instantly in Expo Go.


## Usage Flow
1. Onboarding → Create or verify your profile.
2. Explore → Browse nomadic dating matches or activity-based friend suggestions.
3. Builder Help → Access premium builder marketplace (subscription required).
4. Messaging → Start chats or join group discussions.
5. Monetization → Unlock premium features via RevenueCat subscription.
